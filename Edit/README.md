# Edit (v1)

The original effects. Unchanged.

| File | Shows up as | Notes |
|---|---|---|
| `ZoomCrop.setting` | ZoomCrop | Zoom to a corner-defined area |
| `ZoomCropPro.setting` | ZoomCropPro | Zoom to a box, fit/fill, keep-inside option |
| `CineFocus_SmoothZoom.setting` | CineFocus | One target, auto in → hold → out, with easing menu |

The `Effects` folder is where Resolve reads the templates from. Install target:

```text
%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Effects
```

These are kept as they were. The rewritten, multi-target and VOX versions live
in the sibling [`v2`](../../v2) folder and install alongside these without
conflict.

See [Effects/README.md](Effects/README.md) for the per-effect notes.
